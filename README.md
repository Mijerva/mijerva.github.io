# mijerva.github.io

The source of [mijerva.github.io](https://mijerva.github.io): a one-page gallery of Mijerva's tools.

It is plain HTML, CSS and a little JavaScript, with no build step and no requests to other sites. To view it locally, serve the folder with any static server, for example `python -m http.server`, and open `http://localhost:8000`.

Add a project in `site.js` (`PROJECTS` and `SLIDES`) and draw its pictures as `<template>` elements in `index.html`.
